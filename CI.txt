Automated checks with GitHub Actions
===================================

Workflow: .github/workflows/ci.yml

Place this project's contents at the root of a GitHub repository, including the
hidden .github folder. The workflow runs on pushes and pull requests. It can also
be started manually using Run workflow in the repository's Actions tab.

Checks
------
1. Install Python dependencies and run the backend unit and integration tests.
2. Run frontend unit tests using Node.js; no npm installation is needed.
3. Only after the tests pass, validate Docker Compose, build the image, and start
   the app with a bounded wait for its health check.
4. Verify the webpage, static assets, and full draft-save-history API flow.
5. Show container logs on failure and remove temporary CI containers and data.

The smoke test creates a fictional saved reply. Its environment is disposable;
CI volume cleanup must not be copied to a deployment containing user records.
No secrets, model API keys, or deployment accounts are needed for these checks.
The workflow has read-only repository permissions.
